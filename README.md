# Courses App

Тестовое задание для Effective Mobile (Android Developer)


## Стек технологий

- **Kotlin** — язык программирования
- **Jetpack Compose** — UI
- **Clean Architecture** — архитектура
- **Multimodule** — многомодульность
- **Retrofit + Moshi** — сеть
- **Room** — локальная БД
- **Koin** — DI
- **Coroutines + Flow** — асинхронность
- **MVVM** — паттерн


## Функционал

- ✅ Экран входа (валидация email, соцсети VK/OK)
- ✅ Главный экран (список курсов, сортировка, избранное)
- ✅ Экран избранного (Flow из Room)
- ✅ Экран профиля (заглушка)
- ✅ Экран деталей курса (реальные данные, лайк)


## Сборка

1. Клонировать репозиторий
2. Открыть в Android Studio
3. Синхронизировать Gradle
4. Запустить приложение
